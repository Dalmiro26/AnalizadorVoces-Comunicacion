# AnalizadorVoces-Comunicacion

## Forma de usar el programa:
### 1. Descargar vs code: https://code.visualstudio.com/download?_exp_download=fb315fc982 
### 2. Descargar python: https://www.python.org/ftp/python/3.13.15/python-3.13.15-amd64.exe
### 3. Al instalar python, marcar la opción "Add Python to PATH"
### 4. En vs code, buscar python en la parte de extensiones y descargar el primero que aparece
### 5. En la terminal de vs code, dirigirse a la carpeta del proyecto y luego ingresar el comando "python -m pip install numpy scipy sounddevice streamlit matplotlib"
### 6. Guardar y ejecutar el proyecto
### 7. Para ejecutar el programa se debe ingresar el comando "streamlit run app.py" en la terminal de vs code
### NOTA: Si hay problemas para ejecutar el programa, cambiar la versión de pynthon a la 3.13, presionando "ctrl + shift + p" e ingresar "Select Interpreter"
